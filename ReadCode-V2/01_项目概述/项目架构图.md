### 2.2 模型加载流程

```mermaid
sequenceDiagram
    participant User as 用户代码
    participant Auto as AutoModel/Tokenizer
    participant Hub as Hugging Face Hub
    participant Dynamic as DynamicModuleLoader
    participant Config as PreTrainedConfig
    participant Model as PreTrainedModel
    
    User->>Auto: from_pretrained(model_name)
    Auto->>Hub: 下载配置文件
    Hub-->>Auto: config.json
    Auto->>Config: 解析配置
    Config-->>Auto: Config对象
    Auto->>Dynamic: 动态加载模型类
    Dynamic-->>Auto: ModelClass
    Auto->>Hub: 下载权重文件
    Hub-->>Auto: model.safetensors
    Auto->>Model: 初始化模型并加载权重
    Model-->>User: Model实例
```

### 3.2 文本生成流程

```mermaid
sequenceDiagram
    participant Prompt as 输入提示
    participant Tokenizer as 分词器
    participant Model as 模型
    participant LogitsProc as Logits处理器
    participant Sampler as 采样器
    participant Output as 输出
    
    Prompt->>Tokenizer: 分词
    Tokenizer-->>Model: input_ids
    loop 生成循环
        Model->>Model: 前向传播
        Model-->>LogitsProc: logits
        LogitsProc-->>Sampler: 处理后的logits
        Sampler-->>Model: 下一个token
    end
    Model-->>Tokenizer: 生成的序列
    Tokenizer-->>Output: 解码文本
```

## 4. 类继承关系

### 4.1 配置类继承

```mermaid
classDiagram
    class PretrainedConfig {
        +from_pretrained()
        +save_pretrained()
        +to_dict()
        +from_dict()
    }
    
    class ModelSpecificConfig {
        +model_type
        +model_specific_params
    }
    
    PretrainedConfig <|-- ModelSpecificConfig
```

### 4.2 模型类继承

```mermaid
classDiagram
    class Module
    class PreTrainedModel {
        +from_pretrained()

        +config
        +device
    }

        +generate()
    }
    class SpecificModel {
        +forward()
    }
    
    Module <|-- PreTrainedModel

    PreTrainedModelWithGeneration <|-- SpecificModel
```
