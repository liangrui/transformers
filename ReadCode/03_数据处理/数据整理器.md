# 数据整理器 (Data Collator)

本文件详细解析数据整理器的作用和使用方法。

---

## 1. DataCollator 概述

DataCollator 负责将多个样本整合成一个 batch，是连接 Dataset 和 DataLoader 的桥梁。

---

## 2. 常用 DataCollator

### 2.1 DefaultDataCollator

最基本的数据整理器，只负责将样本堆叠。

```python
from transformers import DefaultDataCollator

data_collator = DefaultDataCollator()

# 使用
# dataset = ...
# loader = DataLoader(dataset, batch_size=8, collate_fn=data_collator)
```

### 2.2 DataCollatorWithPadding

自动处理 padding。

```python
from transformers import DataCollatorWithPadding

data_collator = DataCollatorWithPadding(
    tokenizer=tokenizer,
    padding="longest",       # "longest" 或 "max_length"
    max_length=128,
    pad_to_multiple_of=8,
    return_tensors="pt"
)
```

### 2.3 DataCollatorForLanguageModeling

用于语言模型任务，提供掩码功能。

```python
from transformers import DataCollatorForLanguageModeling

data_collator = DataCollatorForLanguageModeling(
    tokenizer=tokenizer,
    mlm=True,                  # 是否使用掩码语言模型
    mlm_probability=0.15       # 掩码概率
)
```

### 2.4 DataCollatorForTokenClassification

用于 token 分类任务。

```python
from transformers import DataCollatorForTokenClassification

data_collator = DataCollatorForTokenClassification(
    tokenizer=tokenizer
)
```

### 2.5 DataCollatorForSeq2Seq

用于序列到序列任务。

```python
from transformers import DataCollatorForSeq2Seq

data_collator = DataCollatorForSeq2Seq(
    tokenizer=tokenizer,
    model=model,
    padding="longest",
    max_length=128,
    label_pad_token_id=-100   # 标签填充 ID（会在计算 loss 时忽略）
)
```

---

## 3. 与 Trainer 一起使用

```python
from transformers import Trainer

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    data_collator=data_collator  # 在这里指定
)
```

## 4. 自定义 DataCollator

可以通过继承基类创建自定义数据整理器：

```python
from transformers import DefaultDataCollator
import torch

class MyDataCollator(DefaultDataCollator):
    def __call__(self, features):
        # 自定义处理逻辑
        batch = super().__call__(features)
        
        # 添加自定义处理
        # ...
        
        return batch
```

---

## 5. 关键概念

### 5.1 Padding 策略

- `longest`：padding 到 batch 中最长的序列
- `max_length`：padding 到指定的最大长度
- `do_not_pad`：不 padding（需要自己处理）

### 5.2 Attention Mask

自动生成 attention mask 来标识哪些位置是真实的 token，哪些是 padding。

### 5.3 Label Padding

对于分类任务，通常使用 -100 作为 padding token，这样计算 loss 时会自动忽略这些位置。
