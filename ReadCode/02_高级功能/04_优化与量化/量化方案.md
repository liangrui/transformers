# 量化方案

本文件详细解析 Transformers 库中的各种量化方案。

---

## 1. 量化概述

量化是将模型权重和激活值从高精度（如 FP32）转换为低精度（如 INT8、INT4）的技术，目的是：
- 减小模型大小
- 加快推理速度
- 降低内存占用
- 使模型能在低资源设备上运行

---

## 2. 主要量化方案

### 2.1 BitsAndBytes (8-bit 和 4-bit)

最流行的量化方案之一。

```python
from transformers import AutoModelForCausalLM, BitsAndBytesConfig

# 配置 4-bit 量化
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_use_double_quant=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.bfloat16
)

# 加载模型
model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-2-7b-hf",
    quantization_config=bnb_config,
    device_map="auto"
)
```

**参数说明**：
- `load_in_4bit`/`load_in_8bit`：是否使用 4-bit/8-bit 量化
- `bnb_4bit_quant_type`：量化类型 ("fp4" 或 "nf4")
- `bnb_4bit_compute_dtype`：计算时的数据类型
- `bnb_4bit_use_double_quant`：是否使用双重量化

---

### 2.2 GPTQ

另一种流行的 4-bit 量化方案。

```python
from transformers import AutoModelForCausalLM, GPTQConfig

gptq_config = GPTQConfig(
    bits=4,
    group_size=128,
    dataset="wikitext2",
    desc_act=False,
)

model = AutoModelForCausalLM.from_pretrained(
    "model_name",
    quantization_config=gptq_config
)
```

---

### 2.3 AWQ (Activation-aware Weight Quantization)

```python
from transformers import AutoModelForCausalLM, AwqConfig

awq_config = AwqConfig(
    bits=4,
    group_size=128,
    version="gemm"
)

model = AutoModelForCausalLM.from_pretrained(
    "model_name",
    quantization_config=awq_config
)
```

---

### 2.4 Quanto

PyTorch 原生量化方案。

```python
from transformers import AutoModelForCausalLM, QuantoConfig

quanto_config = QuantoConfig(
    weights="int8",
    activations="int8"
)

model = AutoModelForCausalLM.from_pretrained(
    "model_name",
    quantization_config=quanto_config
)
```

## 3. 量化配置基类

```python
from transformers import AutoConfig, AutoModelForCausalLM

# 方法 1：使用量化配置
quantization_config = BitsAndBytesConfig(...)

# 方法 2：集成到模型配置
config = AutoConfig.from_pretrained("model_name")
config.quantization_config = quantization_config

model = AutoModelForCausalLM.from_pretrained(
    "model_name",
    config=config
)
```

## 4. 使用量化模型推理

量化模型的使用方式与普通模型相同：

```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("model_name")
inputs = tokenizer("Hello, world!", return_tensors="pt").to("cuda")

outputs = model.generate(**inputs, max_new_tokens=50)
```

## 5. 常见问题

### 5.1 选择哪种量化方案？

- **BitsAndBytes**：最易用，推理时量化，无需校准
- **GPTQ**：需要校准，但推理速度快，支持多卡
- **AWQ**：性能良好，推理快
- **Quanto**：PyTorch 原生，易集成

### 5.2 性能与精度权衡

- 量化位数越低，内存占用越小，但可能影响精度
- 使用更大的 group size 可以提高精度，但会增加内存
- 某些任务（如代码生成）对量化更敏感

---

## 6. 微调量化模型 (PEFT)

可以使用 PEFT (Parameter-Efficient Fine-Tuning) 来微调量化模型：

```python
from peft import LoraConfig, get_peft_model

lora_config = LoraConfig(
    r=8,
    lora_alpha=32,
    target_modules=["q_proj", "v_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)

model = get_peft_model(model, lora_config)
```
