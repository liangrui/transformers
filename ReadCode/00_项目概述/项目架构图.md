## 2. 核心组件关系图

展示核心类之间的关系：

```mermaid
classDiagram
    class PreTrainedConfig {
        +from_pretrained()
        +save_pretrained()
        +to_dict()
    }
    
    class PreTrainedModel {
        +from_pretrained()
        +save_pretrained()
        +forward()
        +generate()
    }
    
    class PreTrainedTokenizerBase {
        +from_pretrained()
        +save_pretrained()
        +tokenize()
        +encode()
        +decode()
    }
    
    class GenerationMixin {
        +generate()
        +sample()
        +greedy_search()
        +beam_search()
    }
    
    PreTrainedModel *-- PreTrainedConfig : 使用
    PreTrainedModel --|> GenerationMixin : 继承
    PreTrainedTokenizerBase *-- PreTrainedConfig : 使用
    
    class AutoConfig {
        +from_pretrained()
    }
    
    class AutoModel {
        +from_pretrained()
    }
    
    class AutoTokenizer {
        +from_pretrained()
    }
    
    AutoConfig ..> PreTrainedConfig : 创建
    AutoModel ..> PreTrainedModel : 创建
    AutoTokenizer ..> PreTrainedTokenizerBase : 创建
```

## 3. 模型加载流程图

展示 `from_pretrained` 的工作流程：

```mermaid
sequenceDiagram
    participant User as 用户代码
    participant Auto as AutoModel
    participant Config as PreTrainedConfig
    participant Hub as Hugging Face Hub
    participant Model as PreTrainedModel
    
    User->>Auto: from_pretrained(model_name)
    Auto->>Config: 加载配置
    Config->>Hub: 下载 config.json
    Hub-->>Config: 返回配置
    Auto->>Model: 根据配置创建模型实例
    Model->>Hub: 下载模型权重
    Hub-->>Model: 返回权重
    Model->>Model: 加载权重
    Auto-->>User: 返回模型实例
```
