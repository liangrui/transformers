# Hugging Face Transformers 模型实现模式深度分析

> 以 LLaMA 模型为主线，对比 BERT（Encoder-only），系统梳理 Transformers 框架中单个模型的完整实现模式。

---

## 一、模型目录结构约定

每个模型在 `src/transformers/models/` 下拥有独立子目录，遵循统一的文件命名规范：

```
models/llama/
├── __init__.py                        # 模块入口（懒加载）
├── configuration_llama.py             # Config 定义
├── modeling_llama.py                  # Model 实现（核心）
├── tokenization_llama.py              # Tokenizer
├── convert_llama_weights_to_hf.py     # 权重转换脚本
└── [modular_llama.py]                 # Modular 模式（可选，LLaMA 暂无）
```

BERT 目录结构类似：

```
models/bert/
├── __init__.py
├── configuration_bert.py
├── modeling_bert.py
├── tokenization_bert.py
├── tokenization_bert_legacy.py
├── convert_bert_original_tf_checkpoint_to_pytorch.py
├── convert_bert_original_tf2_checkpoint_to_pytorch.py
└── convert_bert_token_dropping_original_tf2_checkpoint_to_pytorch.py
```

**命名约定**：
- 文件名格式：`{类型}_{模型名}.py`，如 `configuration_llama.py`、`modeling_llama.py`
- 类名格式：`{ModelName}{Component}`，如 `LlamaConfig`、`LlamaModel`、`LlamaAttention`
- `__all__` 列表显式声明模块公开的类

## 二、Config 定义模式

### 2.1 基本结构

Config 类继承自 `PreTrainedConfig`，使用 `@auto_docstring` 和 `@strict` 装饰器：

```python
@auto_docstring(checkpoint="meta-llama/Llama-2-7b-hf")
@strict
class LlamaConfig(PreTrainedConfig):
    model_type = "llama"
    keys_to_ignore_at_inference = ["past_key_values"]
    ...
```

**关键要素**：

| 要素 | 说明 | LLaMA 示例 | BERT 示例 |
|------|------|-----------|-----------|
| `model_type` | 模型类型标识符，用于 AutoModel 分发 | `"llama"` | `"bert"` |
| `keys_to_ignore_at_inference` | 推理时忽略的键 | `["past_key_values"]` | 无 |
| `base_model_tp_plan` | 张量并行切分方案 | 有（见下文） | 无 |
| `base_model_pp_plan` | 流水线并行切分方案 | 有（见下文） | 无 |
| 类属性默认值 | 使用 Python 类型注解声明 | `vocab_size: int = 32000` | `vocab_size: int = 30522` |
| `__post_init__` | 初始化后派生计算 | 计算 `head_dim`、`num_key_value_heads` | 无 |
| `validate_architecture` | `@strict` 驱动的架构校验 | 校验 hidden_size 整除 num_attention_heads | 无 |

### 2.2 LlamaConfig 详解

LlamaConfig 使用 Python 3.10+ 的类型注解语法（`int | None`）声明字段，配合 `@strict` 装饰器实现数据类式的严格验证：

```python
class LlamaConfig(PreTrainedConfig):
    model_type = "llama"
    keys_to_ignore_at_inference = ["past_key_values"]

    # 并行方案
    base_model_tp_plan = {
        "layers.*.self_attn.q_proj": "colwise",
        "layers.*.self_attn.k_proj": "colwise",
        "layers.*.self_attn.v_proj": "colwise",
        "layers.*.self_attn.o_proj": "rowwise",
        "layers.*.mlp.gate_proj": "colwise",
        "layers.*.mlp.up_proj": "colwise",
        "layers.*.mlp.down_proj": "rowwise",
    }
    base_model_pp_plan = {
        "embed_tokens": (["input_ids"], ["inputs_embeds"]),
        "layers": (["hidden_states", "attention_mask"], ["hidden_states"]),
        "norm": (["hidden_states"], ["hidden_states"]),
    }

    # 模型超参数
    vocab_size: int = 32000
    hidden_size: int = 4096
    intermediate_size: int = 11008
    num_hidden_layers: int = 32
    num_attention_heads: int = 32
    num_key_value_heads: int | None = None       # GQA 支持
    hidden_act: str = "silu"
    max_position_embeddings: int = 2048
    initializer_range: float = interval(min=0.0, max=1.0)(default=0.02)
    rms_norm_eps: float = 1e-6
    use_cache: bool = True
    pad_token_id: int | None = None
    bos_token_id: int | None = 1
    eos_token_id: int | list[int] | None = 2
    pretraining_tp: int | None = 1
    tie_word_embeddings: bool = False
    rope_parameters: RopeParameters | dict | None = None
    attention_bias: bool = False
    attention_dropout: int | float | None = 0.0
    mlp_bias: bool = False
    head_dim: int | None = None
```

**`__post_init__` 派生逻辑**：

```python
def __post_init__(self, **kwargs):
    if self.head_dim is None:
        self.head_dim = self.hidden_size // self.num_attention_heads
    if self.num_key_value_heads is None:
        self.num_key_value_heads = self.num_attention_heads
    super().__post_init__(**kwargs)
```

当 `num_key_value_heads` 未指定时，默认等于 `num_attention_heads`（即 MHA 模式）；设为更小值时启用 GQA（Grouped Query Attention）。

### 2.3 BertConfig 对比

BertConfig 更简洁，没有并行方案和 RoPE 参数：

```python
class BertConfig(PreTrainedConfig):
    model_type = "bert"
    vocab_size: int = 30522
    hidden_size: int = 768
    num_hidden_layers: int = 12
    num_attention_heads: int = 12
    intermediate_size: int = 3072
    hidden_act: str = "gelu"
    hidden_dropout_prob: float | int = 0.1
    attention_probs_dropout_prob: float | int = 0.1
    max_position_embeddings: int = 512
    type_vocab_size: int = 2
    initializer_range: float = 0.02
    layer_norm_eps: float = 1e-12
    pad_token_id: int | None = 0
    use_cache: bool = True
    classifier_dropout: float | int | None = None
    is_decoder: bool = False
    add_cross_attention: bool = False
    tie_word_embeddings: bool = True
```

**关键差异**：
- BERT 有 `type_vocab_size`（token type embedding）、`is_decoder`、`add_cross_attention`
- BERT 使用 `layer_norm_eps`，LLaMA 使用 `rms_norm_eps`
- BERT 有 `hidden_dropout_prob` 和 `attention_probs_dropout_prob`，LLaMA 默认无 dropout
- LLaMA 有 `rope_parameters`（RoPE 配置），BERT 使用绝对位置编码
- LLaMA 有 `num_key_value_heads`（GQA），BERT 无此概念

## 三、Model 实现模式（组件拆解）

### 3.1 整体架构层次

LLaMA 的 model 文件按以下层次组织：

```
LlamaRMSNorm          — 归一化层
LlamaRotaryEmbedding  — 旋转位置编码
apply_rotary_pos_emb  — RoPE 应用函数
LlamaMLP              — 前馈网络
repeat_kv             — GQA 键值重复
eager_attention_forward — 模块级注意力计算函数
LlamaAttention        — 注意力模块
LlamaDecoderLayer     — 解码器层
LlamaPreTrainedModel  — 预训练基类
LlamaModel            — 基础模型
LlamaForCausalLM      — 因果语言模型
LlamaForSequenceClassification  — 序列分类
LlamaForQuestionAnswering       — 问答
LlamaForTokenClassification     — Token 分类
```

BERT 的层次结构：

```
BertEmbeddings         — 嵌入层（word + position + token_type）
BertSelfAttention      — 自注意力
BertCrossAttention     — 交叉注意力
BertSelfOutput         — 注意力输出投影 + 残差 + LayerNorm
BertAttention          — 注意力组合（self + output）
BertIntermediate       — FFN 第一层（升维 + 激活）
BertOutput             — FFN 第二层（降维 + 残差 + LayerNorm）
BertLayer              — 编码器层
BertEncoder            — 编码器堆叠
BertPooler             — 池化层
BertPreTrainedModel    — 预训练基类
BertModel              — 基础模型
BertForPreTraining     — 预训练头（MLM + NSP）
BertForMaskedLM        — 掩码语言模型
BertLMHeadModel        — 因果语言模型
BertForSequenceClassification — 序列分类
BertForMultipleChoice  — 多选
BertForTokenClassification — Token 分类
BertForQuestionAnswering — 问答
```

### 3.2 LlamaRMSNorm — 归一化层

```python
@use_kernel_forward_from_hub("RMSNorm")
class LlamaRMSNorm(nn.Module):
    def __init__(self, hidden_size, eps: float = 1e-6):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(hidden_size))
        self.variance_epsilon = eps

    def forward(self, hidden_states):
        input_dtype = hidden_states.dtype
        hidden_states = hidden_states.to(torch.float32)
        variance = hidden_states.pow(2).mean(-1, keepdim=True)
        hidden_states = hidden_states * torch.rsqrt(variance + self.variance_epsilon)
        return self.weight * hidden_states.to(input_dtype)
```

**设计要点**：
- **RMSNorm vs LayerNorm**：RMSNorm 去掉了均值中心化步骤，只做缩放，计算更高效
- **精度保护**：先转 float32 计算方差，再转回原精度，避免半精度下溢
- **`@use_kernel_forward_from_hub`**：装饰器允许从 HuggingFace Hub 加载优化的自定义 kernel 替代默认实现
- **等价于 T5LayerNorm**：代码注释明确说明 `LlamaRMSNorm is equivalent to T5LayerNorm`

**对比 BERT**：BERT 使用标准的 `nn.LayerNorm`，包含均值中心化和偏置项：
```python
self.LayerNorm = nn.LayerNorm(config.hidden_size, eps=config.layer_norm_eps)
```

### 3.3 LlamaRotaryEmbedding — 旋转位置编码

```python
class LlamaRotaryEmbedding(nn.Module):
    inv_freq: torch.Tensor

    def __init__(self, config: LlamaConfig, device=None):
        super().__init__()
        self.max_seq_len_cached = config.max_position_embeddings
        self.original_max_seq_len = config.max_position_embeddings
        self.config = config
        self.rope_type = self.config.rope_parameters["rope_type"]

        rope_init_fn = self.compute_default_rope_parameters
        if self.rope_type != "default":
            rope_init_fn = ROPE_INIT_FUNCTIONS[self.rope_type]
        inv_freq, self.attention_scaling = rope_init_fn(self.config, device)

        self.register_buffer("inv_freq", inv_freq, persistent=False)
        self.register_buffer("original_inv_freq", inv_freq.clone(), persistent=False)
```

**设计要点**：
- **`inv_freq` 非持久化**：`persistent=False` 意味着不随模型保存，每次从 config 重新计算
- **多种 RoPE 类型**：通过 `ROPE_INIT_FUNCTIONS` 字典支持不同 RoPE 变体（default、llama3、longrope 等）
- **`@dynamic_rope_update` 装饰器**：在 forward 中根据序列长度动态更新频率（用于 LongRoPE 等变体）
- **`attention_scaling`**：后处理缩放因子，某些 RoPE 变体需要

**`compute_default_rope_parameters` 静态方法**：

```python
@staticmethod
def compute_default_rope_parameters(config, device=None, seq_len=None):
    base = config.rope_parameters["rope_theta"]
    dim = getattr(config, "head_dim", None) or config.hidden_size // config.num_attention_heads
    attention_factor = 1.0
    inv_freq = 1.0 / (base ** (torch.arange(0, dim, 2, dtype=torch.int64).to(device=device, dtype=torch.float) / dim))
    return inv_freq, attention_factor
```

**forward 方法**：

```python
@torch.no_grad()
@dynamic_rope_update
def forward(self, x, position_ids):
    inv_freq_expanded = self.inv_freq[None, :, None].float().expand(position_ids.shape[0], -1, 1).to(x.device)
    position_ids_expanded = position_ids[:, None, :].float()
    with maybe_autocast(device_type=device_type, enabled=False):
        freqs = (inv_freq_expanded.float() @ position_ids_expanded.float()).transpose(1, 2)
        emb = torch.cat((freqs, freqs), dim=-1)
        cos = emb.cos() * self.attention_scaling
        sin = emb.sin() * self.attention_scaling
    return cos.to(dtype=x.dtype), sin.to(dtype=x.dtype)
```

**对比 BERT**：BERT 使用**可学习的绝对位置嵌入**（`nn.Embedding`），在 `BertEmbeddings` 中与 word embedding 和 token_type embedding 相加。这是 Encoder-only 模型的典型做法。

### 3.4 apply_rotary_pos_emb — RoPE 应用

```python
@use_kernel_func_from_hub("rotary_pos_emb")
def apply_rotary_pos_emb(q, k, cos, sin, unsqueeze_dim=1):
    cos = cos.unsqueeze(unsqueeze_dim)
    sin = sin.unsqueeze(unsqueeze_dim)
    q_embed = (q * cos) + (rotate_half(q) * sin)
    k_embed = (k * cos) + (rotate_half(k) * sin)
    return q_embed, k_embed

def rotate_half(x):
    x1 = x[..., : x.shape[-1] // 2]
    x2 = x[..., x.shape[-1] // 2 :]
    return torch.cat((-x2, x1), dim=-1)
```

**数学原理**：将向量分成两半，通过旋转矩阵的等价形式应用位置信息。`unsqueeze_dim` 参数控制广播维度，适配 `[batch, heads, seq, dim]` 或 `[batch, seq, heads, dim]` 两种布局。

### 3.5 LlamaMLP — 前馈网络

```python
class LlamaMLP(nn.Module):
    def __init__(self, config):
        super().__init__()
        self.hidden_size = config.hidden_size
        self.intermediate_size = config.intermediate_size
        self.gate_proj = nn.Linear(self.hidden_size, self.intermediate_size, bias=config.mlp_bias)
        self.up_proj = nn.Linear(self.hidden_size, self.intermediate_size, bias=config.mlp_bias)
        self.down_proj = nn.Linear(self.intermediate_size, self.hidden_size, bias=config.mlp_bias)
        self.act_fn = ACT2FN[config.hidden_act]

    def forward(self, x):
        down_proj = self.down_proj(self.act_fn(self.gate_proj(x)) * self.up_proj(x))
        return down_proj
```

**SwiGLU 结构**：`down_proj(SiLU(gate_proj(x)) * up_proj(x))`，这是 LLaMA 的核心创新之一，相比标准 FFN 多了一个门控投影。

**对比 BERT**：BERT 使用标准两层 FFN，拆分为 `BertIntermediate` 和 `BertOutput` 两个类：
```python
# BertIntermediate: hidden_size → intermediate_size + GELU
# BertOutput: intermediate_size → hidden_size + dropout + residual + LayerNorm
```
BERT 的 FFN 还支持 `apply_chunking_to_forward` 分块计算以节省显存。

### 3.6 repeat_kv — GQA 支持

```python
def repeat_kv(hidden_states, n_rep):
    batch, num_key_value_heads, slen, head_dim = hidden_states.shape
    if n_rep == 1:
        return hidden_states
    hidden_states = hidden_states[:, :, None, :, :].expand(batch, num_key_value_heads, n_rep, slen, head_dim)
    return hidden_states.reshape(batch, num_key_value_heads * n_rep, slen, head_dim)
```

当 `num_key_value_heads < num_attention_heads` 时（GQA），需要将 KV 头复制 `n_rep` 次以匹配 Q 头数。`n_rep=1` 时直接返回，无额外开销。

### 3.7 eager_attention_forward — 模块级注意力函数

```python
def eager_attention_forward(module, query, key, value, attention_mask, scaling, dropout=0.0, **kwargs):
    key_states = repeat_kv(key, module.num_key_value_groups)
    value_states = repeat_kv(value, module.num_key_value_groups)
    attn_weights = torch.matmul(query, key_states.transpose(2, 3)) * scaling
    if attention_mask is not None:
        attn_weights = attn_weights + attention_mask
    attn_weights = nn.functional.softmax(attn_weights, dim=-1, dtype=torch.float32).to(query.dtype)
    attn_weights = nn.functional.dropout(attn_weights, p=dropout, training=module.training)
    attn_output = torch.matmul(attn_weights, value_states)
    attn_output = attn_output.transpose(1, 2).contiguous()
    return attn_output, attn_weights
```

**设计模式**：注意力计算被提取为**模块级函数**而非类方法，这是 Transformers 的统一模式。好处：
1. 可以被 `ALL_ATTENTION_FUNCTIONS` 注册表分发到不同实现（eager、flash_attention、sdpa、flex_attention）
2. 函数签名统一，便于替换
3. softmax 在 float32 下计算以保证数值稳定性

### 3.8 LlamaAttention — 注意力模块

```python
@use_kernelized_func(apply_rotary_pos_emb)
class LlamaAttention(nn.Module):
    def __init__(self, config: LlamaConfig, layer_idx: int):
        super().__init__()
        self.config = config
        self.layer_idx = layer_idx
        self.head_dim = getattr(config, "head_dim", config.hidden_size // config.num_attention_heads)
        self.num_key_value_groups = config.num_attention_heads // config.num_key_value_heads
        self.scaling = self.head_dim**-0.5
        self.attention_dropout = config.attention_dropout
        self.is_causal = True

        self.q_proj = nn.Linear(config.hidden_size, config.num_attention_heads * self.head_dim, bias=config.attention_bias)
        self.k_proj = nn.Linear(config.hidden_size, config.num_key_value_heads * self.head_dim, bias=config.attention_bias)
        self.v_proj = nn.Linear(config.hidden_size, config.num_key_value_heads * self.head_dim, bias=config.attention_bias)
        self.o_proj = nn.Linear(config.num_attention_heads * self.head_dim, config.hidden_size, bias=config.attention_bias)
```

**设计要点**：
- **`layer_idx`**：每层传入层索引，用于 KV cache 的层定位
- **GQA 支持**：`q_proj` 输出维度 = `num_attention_heads * head_dim`，`k_proj/v_proj` 输出维度 = `num_key_value_heads * head_dim`
- **默认无 bias**：`config.attention_bias` 默认为 `False`，这是 LLaMA 的设计选择
- **`@use_kernelized_func`**：装饰器允许用 Hub 上的优化 kernel 替换 `apply_rotary_pos_emb`

**forward 流程**：

```python
def forward(self, hidden_states, position_embeddings, attention_mask, past_key_values, **kwargs):
    # 1. 线性投影 + reshape 为多头格式
    query_states = self.q_proj(hidden_states).view(hidden_shape).transpose(1, 2)
    key_states = self.k_proj(hidden_states).view(hidden_shape).transpose(1, 2)
    value_states = self.v_proj(hidden_states).view(hidden_shape).transpose(1, 2)

    # 2. 应用 RoPE
    cos, sin = position_embeddings
    query_states, key_states = apply_rotary_pos_emb(query_states, key_states, cos, sin)

    # 3. KV cache 更新
    if past_key_values is not None:
        key_states, value_states = past_key_values.update(key_states, value_states, self.layer_idx)

    # 4. 通过注意力接口分发
    attention_interface = ALL_ATTENTION_FUNCTIONS.get_interface(
        self.config._attn_implementation, eager_attention_forward
    )
    attn_output, attn_weights = attention_interface(
        self, query_states, key_states, value_states, attention_mask,
        dropout=..., scaling=self.scaling, **kwargs,
    )

    # 5. 输出投影
    attn_output = attn_output.reshape(*input_shape, -1).contiguous()
    attn_output = self.o_proj(attn_output)
    return attn_output, attn_weights
```

**对比 BERT**：BERT 的 `BertSelfAttention` 结构更复杂：
- 有 `BertSelfAttention` + `BertSelfOutput` + `BertAttention` 三层封装
- `BertSelfOutput` 包含 dense + dropout + LayerNorm + 残差连接
- 支持 `BertCrossAttention`（交叉注意力）
- 无 RoPE，无 GQA，Q/K/V 维度相同

### 3.9 LlamaDecoderLayer — 解码器层

```python
class LlamaDecoderLayer(GradientCheckpointingLayer):
    def __init__(self, config: LlamaConfig, layer_idx: int):
        super().__init__()
        self.hidden_size = config.hidden_size
        self.self_attn = LlamaAttention(config=config, layer_idx=layer_idx)
        self.mlp = LlamaMLP(config)
        self.input_layernorm = LlamaRMSNorm(config.hidden_size, eps=config.rms_norm_eps)
        self.post_attention_layernorm = LlamaRMSNorm(config.hidden_size, eps=config.rms_norm_eps)

    def forward(self, hidden_states, attention_mask, position_ids, past_key_values, use_cache, position_embeddings, **kwargs):
        # Pre-Norm 架构：先归一化再计算
        residual = hidden_states
        hidden_states = self.input_layernorm(hidden_states)
        hidden_states, _ = self.self_attn(...)
        hidden_states = residual + hidden_states

        residual = hidden_states
        hidden_states = self.post_attention_layernorm(hidden_states)
        hidden_states = self.mlp(hidden_states)
        hidden_states = residual + hidden_states
        return hidden_states
```

**设计要点**：
- **Pre-Norm 架构**：LLaMA 使用 Pre-LN（先归一化再计算），BERT 使用 Post-LN（先计算再归一化）
- **两个 RMSNorm**：`input_layernorm`（注意力前）和 `post_attention_layernorm`（FFN 前）
- **继承 `GradientCheckpointingLayer`**：自动支持梯度检查点，训练时节省显存
- **残差连接**：手动管理 `residual` 变量，清晰明确

**对比 BERT**：
- BERT 使用 Post-Norm：`LayerNorm(x + Sublayer(x))`
- BERT 的 LayerNorm 在 `BertSelfOutput` 和 `BertOutput` 内部
- BERT 支持 cross-attention 子层（当 `is_decoder=True` 且 `add_cross_attention=True`）

### 3.10 LlamaPreTrainedModel — 预训练基类

```python
@auto_docstring
class LlamaPreTrainedModel(PreTrainedModel):

```

**关键属性说明**：

| 属性 | 说明 |
|------|------|
| `base_model_prefix` | 基础模型在子类中的属性名（LLaMA 为 `"model"`，BERT 为 `"bert"`） |
| `_no_split_modules` | 模型并行时不可拆分的模块列表 |
| `_skip_keys_device_placement` | 跳过设备放置的键（KV cache 自行管理设备） |
| `_supports_flash_attn` | 支持 Flash Attention |
| `_supports_sdpa` | 支持 PyTorch SDPA |
| `_can_compile_fullgraph` | 支持 `torch.compile` 全图编译 |
| `_can_record_outputs` | 输出记录映射，用于 `output_hidden_states` 和 `output_attentions` |

### 3.11 LlamaModel — 基础模型

```python
@auto_docstring
class LlamaModel(LlamaPreTrainedModel):
    def __init__(self, config: LlamaConfig):
        super().__init__(config)
        self.padding_idx = config.pad_token_id
        self.vocab_size = config.vocab_size
        self.embed_tokens = nn.Embedding(config.vocab_size, config.hidden_size, self.padding_idx)
        self.layers = nn.ModuleList(
            [LlamaDecoderLayer(config, layer_idx) for layer_idx in range(config.num_hidden_layers)]
        )
        self.norm = LlamaRMSNorm(config.hidden_size, eps=config.rms_norm_eps)
        self.rotary_emb = LlamaRotaryEmbedding(config=config)
        self.gradient_checkpointing = False
        self.post_init()
```

**forward 核心流程**：

```python
@merge_with_config_defaults
@capture_outputs
@auto_docstring
def forward(self, input_ids, attention_mask, position_ids, past_key_values, inputs_embeds, use_cache, **kwargs):
    # 1. 嵌入
    if inputs_embeds is None:
        inputs_embeds = self.embed_tokens(input_ids)

    # 2. 初始化 KV cache
    if use_cache and past_key_values is None:
        past_key_values = DynamicCache(config=self.config)

    # 3. 计算 position_ids
    if position_ids is None:
        past_seen_tokens = past_key_values.get_seq_length() if past_key_values is not None else 0
        position_ids = torch.arange(inputs_embeds.shape[1], device=inputs_embeds.device) + past_seen_tokens
        position_ids = position_ids.unsqueeze(0)

    # 4. 创建因果掩码
    causal_mask = create_causal_mask(
        config=self.config, inputs_embeds=inputs_embeds,
        attention_mask=attention_mask, past_key_values=past_key_values, position_ids=position_ids,
    )

    # 5. 计算 RoPE
    hidden_states = inputs_embeds
    position_embeddings = self.rotary_emb(hidden_states, position_ids=position_ids)

    # 6. 逐层前向
    for decoder_layer in self.layers[:self.config.num_hidden_layers]:
        hidden_states = decoder_layer(
            hidden_states, attention_mask=causal_mask,
            position_embeddings=position_embeddings, position_ids=position_ids,
            past_key_values=past_key_values, use_cache=use_cache, **kwargs,
        )

    # 7. 最终归一化
    hidden_states = self.norm(hidden_states)
    return BaseModelOutputWithPast(last_hidden_state=hidden_states, past_key_values=past_key_values)
```

**装饰器说明**：
- `@merge_with_config_defaults`：将 config 中的默认值合并到函数参数
- `@capture_outputs`：捕获 hidden_states 和 attentions 输出（由 `_can_record_outputs` 控制）
- `@auto_docstring`：自动生成文档字符串

**对比 BERT**：
- BERT 有 `BertEmbeddings`（word + position + token_type 三合一嵌入层）
- BERT 有 `BertEncoder`（编码器堆叠，独立类）
- BERT 有 `BertPooler`（取 [CLS] token 做池化）
- BERT 掩码使用 `create_bidirectional_mask`（双向注意力）
- LLaMA 掩码使用 `create_causal_mask`（因果注意力）

### 3.12 LlamaForCausalLM — 因果语言模型

```python
@auto_docstring
class LlamaForCausalLM(LlamaPreTrainedModel, GenerationMixin):
    _tied_weights_keys = {"lm_head.weight": "model.embed_tokens.weight"}
    _tp_plan = {"lm_head": "colwise_gather_output"}
    _pp_plan = {"lm_head": (["hidden_states"], ["logits"])}

    def __init__(self, config):
        super().__init__(config)
        self.model = LlamaModel(config)
        self.vocab_size = config.vocab_size
        self.lm_head = nn.Linear(config.hidden_size, config.vocab_size, bias=False)
        self.post_init()
```

**forward 核心逻辑**：

```python
@can_return_tuple
@auto_docstring
def forward(self, input_ids, attention_mask, position_ids, past_key_values, inputs_embeds,
            labels, use_cache, logits_to_keep, **kwargs):
    outputs = self.model(...)
    hidden_states = outputs.last_hidden_state

    # 高效 logits 计算：只计算需要的 token
    slice_indices = slice(-logits_to_keep, None) if isinstance(logits_to_keep, int) else logits_to_keep
    logits = self.lm_head(hidden_states[:, slice_indices, :])

    loss = None
    if labels is not None:
        loss = self.loss_function(logits=logits, labels=labels, vocab_size=self.config.vocab_size, **kwargs)

    return CausalLMOutputWithPast(loss=loss, logits=logits, past_key_values=outputs.past_key_values, ...)
```

**设计要点**：
- **`GenerationMixin`**：混入生成能力（`generate()` 方法）
- **`_tied_weights_keys`**：声明 `lm_head.weight` 与 `model.embed_tokens.weight` 共享（但 `tie_word_embeddings=False` 时不共享）
- **`logits_to_keep`**：推理时只计算最后几个 token 的 logits，大幅节省计算
- **`loss_function`**：基类提供的标准交叉熵损失函数

### 3.13 通用任务头（Generic Heads）

LLaMA 的序列分类、问答、Token 分类头使用了 `modeling_layers.py` 中的通用实现：

```python
class LlamaForSequenceClassification(GenericForSequenceClassification, LlamaPreTrainedModel): ...
class LlamaForQuestionAnswering(GenericForQuestionAnswering, LlamaPreTrainedModel): ...
class LlamaForTokenClassification(GenericForTokenClassification, LlamaPreTrainedModel): ...
```

**`GenericForSequenceClassification`** 的核心逻辑：
- 通过 `AutoModel.from_config(config)` 自动创建基础模型
- 使用 `setattr(self, self.base_model_prefix, ...)` 动态设置属性名
- 取最后一个非 padding token 的 logits 做分类

**对比 BERT**：BERT 的每个任务头都是**完全独立实现**的，没有使用通用基类。这是因为 BERT 出现更早，通用模式是后来才引入的。

## 四、Modular 模式

### 4.1 概念

Modular 模式是 Transformers 近期引入的代码复用机制。当新模型与已有模型高度相似时，可以通过 `modular_*.py` 文件**继承和覆盖**已有组件，避免代码重复。

### 4.2 LLaMA 的 Modular 情况

LLaMA 目前**没有** `modular_llama.py`，因为 LLaMA 本身是许多模型的基础参考实现。但其他模型通过 modular 模式复用 LLaMA 组件：

**Qwen3 示例**（[modular_qwen3.py](file:///workspace/src/transformers/models/qwen3/modular_qwen3.py)）：

```python
from ..llama.modeling_llama import LlamaAttention
from ..qwen2.modeling_qwen2 import (
    Qwen2ForCausalLM,
    Qwen2RMSNorm,
    Qwen2RotaryEmbedding,
    apply_rotary_pos_emb,
    eager_attention_forward,
)

class Qwen3RMSNorm(Qwen2RMSNorm):
    pass

class Qwen3MLP(GemmaMLP):
    pass

class Qwen3Attention(LlamaAttention):
    def __init__(self, config, layer_idx):
        self.layer_type = config.layer_types[layer_idx] if hasattr(config, "layer_types") else None
        super().__init__(config, layer_idx)
        self.q_norm = Qwen3RMSNorm(self.head_dim, eps=config.rms_norm_eps)
        self.k_norm = Qwen3RMSNorm(self.head_dim, eps=config.rms_norm_eps)
        self.sliding_window = config.sliding_window if self.layer_type == "sliding_attention" else None

class Qwen3ForCausalLM(Qwen2ForCausalLM):
    def forward(self, **super_kwargs):
        return super().forward(**super_kwargs)
```

### 4.3 Modular 模式的复用层次

```
LlamaAttention  ←── Qwen3Attention（增加 q_norm/k_norm/sliding_window）
Qwen2RMSNorm   ←── Qwen3RMSNorm（直接 pass-through）
Qwen2ForCausalLM ←── Qwen3ForCausalLM（覆盖 forward）
GemmaMLP       ←── Qwen3MLP（直接 pass-through）
```

**模式总结**：
- **Pass-through 继承**：`class XNorm(ParentNorm): pass` — 仅为了命名空间隔离
- **增量覆盖**：继承父类并在 `__init__` 或 `forward` 中添加新功能
- **跨模型引用**：可以从不同模型导入组件（如 Qwen3 同时引用 LLaMA 和 Qwen2 和 Gemma）

## 五、权重转换脚本模式

### 5.1 整体结构

[convert_llama_weights_to_hf.py](file:///workspace/src/transformers/models/llama/convert_llama_weights_to_hf.py) 负责将 Meta 官方发布的 LLaMA 权重格式转换为 HuggingFace 格式：

```
Meta 格式                          →    HuggingFace 格式
consolidated.00.pth, ...          →    pytorch_model-*.bin / model.safetensors
params.json                       →    config.json
tokenizer.model                   →    tokenizer.json / tokenizer.model
                                       generation_config.json
```

### 5.2 核心函数

**`write_model()`**：权重转换主函数

1. **读取原始参数**：从 `params.json` 读取模型结构参数
2. **处理分片**：支持单分片和多分片（sharded）权重
3. **权重名称映射**：

| Meta 原始名称 | HuggingFace 名称 |
|--------------|-----------------|
| `layers.{i}.attention.wq.weight` | `model.layers.{i}.self_attn.q_proj.weight` |
| `layers.{i}.attention.wk.weight` | `model.layers.{i}.self_attn.k_proj.weight` |
| `layers.{i}.attention.wv.weight` | `model.layers.{i}.self_attn.v_proj.weight` |
| `layers.{i}.attention.wo.weight` | `model.layers.{i}.self_attn.o_proj.weight` |
| `layers.{i}.feed_forward.w1.weight` | `model.layers.{i}.mlp.gate_proj.weight` |
| `layers.{i}.feed_forward.w2.weight` | `model.layers.{i}.mlp.down_proj.weight` |
| `layers.{i}.feed_forward.w3.weight` | `model.layers.{i}.mlp.up_proj.weight` |
| `layers.{i}.attention_norm.weight` | `model.layers.{i}.input_layernorm.weight` |
| `layers.{i}.ffn_norm.weight` | `model.layers.{i}.post_attention_layernorm.weight` |
| `tok_embeddings.weight` | `model.embed_tokens.weight` |
| `norm.weight` | `model.norm.weight` |
| `output.weight` | `lm_head.weight` |

4. **`permute` 操作**：对 Q/K 权重做旋转重排，适配 RoPE 的实现方式差异
5. **分片拼接**：多分片权重按 head 维度拼接
6. **保存配置**：创建 `LlamaConfig` 并保存
7. **验证加载**：用 `LlamaForCausalLM.from_pretrained()` 加载验证

**`write_tokenizer()`**：分词器转换

- LLaMA 1/2：使用 `LlamaTokenizer`（基于 SentencePiece）
- LLaMA 3+：使用 `Llama3Converter`（基于 TikToken），继承自 `TikTokenConverter`

### 5.3 版本适配

脚本支持 LLaMA 1/2/3/3.1/3.2/Guard-3 多个版本：

```python
NUM_SHARDS = {"7B": 1, "13B": 2, "30B": 4, "65B": 8, "70B": 8, "405B": 8, ...}
CONTEXT_LENGTH_FOR_VERSION = {"1": 2048, "2": 4096, "3": 8192, "3.1": 131072, "3.2": 131072}
```

不同版本的差异：
- **上下文长度**：从 2048 到 131072
- **特殊 token**：LLaMA 3+ 有大量新增特殊 token（如 `<|start_header_id|>`, `<|eot_id|>`）
- **RoPE 参数**：LLaMA 3.1+ 使用 `llama3` 类型的 RoPE（带缩放因子）
- **权重共享**：LLaMA 3.2 设置 `tie_word_embeddings=True`

## 六、Tokenizer 模式

### 6.1 LlamaTokenizer

```python
class LlamaTokenizer(TokenizersBackend):
    vocab_files_names = VOCAB_FILES_NAMES
```

**设计要点**：

### 6.2 对比 BERT

BERT 使用 `PreTrainedTokenizer`（基于 WordPiece），有 `tokenization_bert.py` 和 `tokenization_bert_legacy.py` 两个版本。

### 7.1 `__init__.py` 懒加载

## 八、Decoder-only vs Encoder-only 的差异总结

| 维度 | Decoder-only (LLaMA) | Encoder-only (BERT) |
|------|----------------------|---------------------|
| **注意力方向** | 因果掩码（下三角） | 双向掩码（全连接） |
| **掩码创建** | `create_causal_mask()` | `create_bidirectional_mask()` |
| **位置编码** | RoPE（旋转位置编码） | 可学习绝对位置嵌入 |
| **归一化** | RMSNorm（Pre-Norm） | LayerNorm（Post-Norm） |
| **FFN** | SwiGLU（gate + up + down） | 标准 FFN（intermediate + output） |
| **注意力类型** | 仅 Self-Attention | Self + Cross-Attention |
| **GQA** | 支持（`num_key_value_heads`） | 不支持 |
| **嵌入层** | 仅 word embedding | word + position + token_type |
| **池化** | 无（取最后 token） | BertPooler（取 [CLS] token） |
| **基础模型前缀** | `"model"` | `"bert"` |
| **权重共享** | `tie_word_embeddings=False` | `tie_word_embeddings=True` |
| **padding 侧** | 左填充 | 右填充 |
| **任务头** | 通用 Generic 基类 | 独立实现 |
| **主要任务** | CausalLM | MaskedLM + NSP |
| **生成能力** | `GenerationMixin` | 无（`BertLMHeadModel` 可选） |
| **并行方案** | TP/PP 方案在 Config 中 | 无 |
| **梯度检查点** | `GradientCheckpointingLayer` | `GradientCheckpointingLayer` |
| **KV Cache** | `DynamicCache` | `DynamicCache` / `EncoderDecoderCache` |
| **输出类型** | `BaseModelOutputWithPast` | `BaseModelOutputWithPoolingAndCrossAttentions` |

### 8.1 架构差异图示

**LLaMA Decoder Layer**（Pre-Norm）：
```
input → RMSNorm → Self-Attention → + → RMSNorm → SwiGLU-FFN → + → output
         ↑________________________|       ↑______________________|
              residual                      residual
```

**BERT Encoder Layer**（Post-Norm）：
```
input → Self-Attention → + → LayerNorm → FFN → + → LayerNorm → output
                           ↑_________________↑       ↑__________|
                              residual                  residual
```

### 8.2 模型层次差异

**LLaMA**（扁平化设计）：
```
LlamaForCausalLM
├── model (LlamaModel)
│   ├── embed_tokens
│   ├── layers (N × LlamaDecoderLayer)
│   │   ├── input_layernorm
│   │   ├── self_attn (LlamaAttention)
│   │   ├── post_attention_layernorm
│   │   └── mlp (LlamaMLP)
│   ├── norm
│   └── rotary_emb
└── lm_head
```

**BERT**（嵌套式设计）：
```
BertForMaskedLM
├── bert (BertModel)
│   ├── embeddings (BertEmbeddings)
│   │   ├── word_embeddings
│   │   ├── position_embeddings
│   │   └── token_type_embeddings
│   ├── encoder (BertEncoder)
│   │   └── layer (N × BertLayer)
│   │       ├── attention (BertAttention)
│   │       │   ├── self (BertSelfAttention)
│   │       │   └── output (BertSelfOutput)
│   │       ├── crossattention (BertCrossAttention, 可选)
│   │       ├── intermediate (BertIntermediate)
│   │       └── output (BertOutput)
│   └── pooler (BertPooler)
└── cls (BertOnlyMLMHead)
    └── predictions (BertLMPredictionHead)
        ├── transform
        └── decoder
```

## 九、关键设计模式总结

### 9.1 组件分层模式

```
原子组件（Norm, Embedding, RoPE）
    ↓
功能模块（Attention, MLP）
    ↓
层组件（DecoderLayer / EncoderLayer）
    ↓
基础模型（LlamaModel / BertModel）
    ↓
任务模型（ForCausalLM / ForMaskedLM / ForSequenceClassification ...）
```

### 9.2 注意力分发模式

通过 `ALL_ATTENTION_FUNCTIONS` 注册表实现注意力后端分发：

```python
attention_interface = ALL_ATTENTION_FUNCTIONS.get_interface(
    self.config._attn_implementation,  # "eager" / "flash_attention_2" / "sdpa" / "flex_attention"
    eager_attention_forward            # 默认回退
)
```

### 9.3 装饰器驱动模式

| 装饰器 | 作用 |
|--------|------|
| `@auto_docstring` | 自动生成文档字符串 |
| `@strict` | 数据类式严格验证 |
| `@can_return_tuple` | 支持返回元组或 ModelOutput |
| `@merge_with_config_defaults` | 合并 config 默认值到函数参数 |
| `@capture_outputs` | 捕获 hidden_states/attentions |
| `@use_kernel_forward_from_hub` | 从 Hub 加载优化 kernel |
| `@use_kernelized_func` | 用 Hub kernel 替换函数 |
| `@dynamic_rope_update` | 动态更新 RoPE 频率 |

### 9.4 通用任务头模式（新式 vs 旧式）

**新式（LLaMA 等）**：使用 `GenericFor*` Mixin
```python
class LlamaForSequenceClassification(GenericForSequenceClassification, LlamaPreTrainedModel): ...
```

**旧式（BERT 等）**：完全独立实现
```python
class BertForSequenceClassification(BertPreTrainedModel):
    def __init__(self, config):
        self.bert = BertModel(config)
        self.dropout = nn.Dropout(...)
        self.classifier = nn.Linear(...)
```

新式模式的优势：
- 代码复用，减少重复
- 通过 `AutoModel.from_config(config)` 自动创建基础模型
- `base_model_prefix` 可配置，适配不同命名

### 9.5 权重转换脚本模式

1. 读取原始格式（`.pth` / TF checkpoint）
2. 名称映射 + 维度变换（如 `permute`）
3. 分片处理（拼接或拆分）
4. 创建 Config + GenerationConfig
5. 保存为 HuggingFace 格式
6. 验证加载

## 十、演进趋势

从 BERT（2018）到 LLaMA（2023+）的实现演进可以看出以下趋势：

1. **Pre-Norm 取代 Post-Norm**：训练更稳定，已成为主流
2. **RoPE 取代可学习位置编码**：更好的长度外推性
3. **RMSNorm 取代 LayerNorm**：计算更高效
4. **SwiGLU 取代标准 FFN**：性能更好
5. **GQA 取代 MHA**：推理更高效
6. **通用任务头取代独立实现**：代码更简洁
7. **装饰器驱动取代手动逻辑**：关注点分离
8. **Kernel 优化集成**：通过 Hub 分发优化 kernel
9. **并行方案内置**：TP/PP 方案直接在 Config 中声明
10. **Modular 模式**：通过继承复用已有组件，减少代码重复
